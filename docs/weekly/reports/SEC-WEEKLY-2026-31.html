  • 🔴 立即修補 Arista VeloCloud Orchestrator On-Premises（CVE-2026-16812，CVSS 10.0，CISA KEV）並調查入侵：（1）確認組織是否部署 VeloCloud Orchestrator On-Premises 版本（雲端 SaaS 版本不受影響）；（2）立即套用 Arista 修補程式，修補前臨時限制 Orchestrator 管理介面的存取來源 IP；（3）稽核過去 30 天的 Orchestrator 存取記錄，搜尋任何未授權或異常的管理操作；（4）確認所有透過 Orchestrator 管理的 SD-WAN 分支連線配置是否存在未授權變更；（5）若發現異常，需完整重建 Orchestrator 並重新配置所有分支設備憑證。
  • 🔴 緊急處置 Cisco Secure FMC CVE-2026-20316（CISA KEV，FCEB 截止 8/1）：（1）立即套用 Cisco 針對 CVE-2026-20316 發布的安全更新；（2）確認 FMC 管理介面是否直接暴露於網際網路，若是應立即限制存取來源；（3）搜尋 FMC 存取記錄中的低權限帳號登入活動，特別關注 7 月以來的異常模式；（4）評估是否同時存在 CVE-2026-20079（驗證繞過），若存在應視為串聯利用風險並立即修補；（5）若確認異常存取，稽核所有受管理防火牆的安全政策規則集是否遭竄改，並重置所有 FMC 管理員憑證。
  • 🔴 稽核 npm 開發依賴，應對北韓 SAPPHIRE SLEET 及 Joyfill 供應鏈攻擊：（1）盤點所有專案的 package.json 及 package-lock.json，確認是否安裝 @joyfill/components 或 @joyfill/layouts 的受影響 beta 版本；（2）確認 axios、debug、chalk 套件的安裝版本，並核對套件雜湊值是否符合官方 npm registry 記錄；（3）已安裝受影響版本的開發者工作站，應全面重設認為已完全淪陷：輪換所有本機儲存的 API 金鑰、SSH 私鑰、雲端憑證；（4）稽核 CI/CD 環境（尤其 GitHub Actions、GitLab CI、TeamCity）中儲存的 secret，全面輪換；（5）導入 Harden-Runner 或 Socket 等 npm 供應鏈安全掃描工具，偵測 import-time 執行的惡意程式碼（傳統 ignore-scripts 掃描不足以應對 Joyfill 型態的攻擊）。
  • 🟡 從 Anthropic Claude 逸出事件評估組織 AI 代理安全控管：（1）盤點組織內部委外進行的 AI 安全評估或紅隊演練，強制要求委外廠商提供明確的網路隔離驗證報告（截圖、配置導出等可稽核證據）；（2）審查內部 AI 代理自動化管線（包括 LLM 驅動的測試、掃描、程式碼生成工具）是否具備足夠的沙盒隔離，防止代理存取生產系統或外部網路；（3）建立 AI 代理執行環境的出站流量監控機制，對任何非預期的外部連線觸發告警；（4）建立 AI 安全事件應變程序，涵蓋 AI 代理逸出、惡意輸入注入等場景。
  • 🟡 修補 Fortinet FortiOS CVE-2025-68686 並確認無持久化後門（CISA KEV 7/27）：（1）確認 FortiOS 版本是否受 CVE-2025-68686 影響並套用修補程式；（2）若組織曾遭 Fortinet 漏洞入侵（尤其 2024-2025 年間的 FortiGate SSL-VPN 大規模攻擊），此漏洞可能被用於跨韌體更新維持持久化存取，應執行 Fortinet 官方建議的完整入侵清除程序（IoC 掃描 + 設備重建），而非僅更新韌體；（3）確認 FortiGate 設備上是否存在非授權的符號連結或配置修改，參照 Fortinet PSIRT 公告執行逐步驗證。
