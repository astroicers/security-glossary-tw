行動建議

  • 🔴 立即緩解 Fortinet FortiMail CVE-2026-104286（CVSS 9.8，積極利用中，CISA KEV 10/1，大多數版本尚無修補）：（1）確認所有 FortiMail 部署版本（8.0.x、7.6.x、7.4.x、7.2.x）；（2）立即執行緩解措施：（a）停用 IBE（Identity-Based Encryption）功能支援；（b）以 ACL 或防火牆規則限制管理介面，僅允許受信任 IP 存取，封鎖外部對管理埠的直接存取；（3）對照 Fortinet 發布的 IoC 清單（攻擊者 IP、可疑文件路徑及組態變更），稽核現有部署是否已遭利用；（4）稽核 FortiMail 系統日誌，搜尋 10/1 前後的可疑 HTTP/HTTPS 請求（異常路徑遍歷字元序列）；（5）有 FortiMail 暴露於外部網路的組織，優先評估是否可能已遭利用，考慮臨時隔離並進行取證分析；（6）持續關注 Fortinet 修補版本（8.0.2、7.6.7、7.4.9）發布進度，一旦發布立即套用。
  • 🔴 確認 Gitea 已升級並稽核 Red Heron 入侵指標（台灣半導體、國防、能源相關組織尤重要）：（1）確認所有 Gitea 自架實例版本，立即升級至 1.27.1 以上——版本 1.17 至 1.27.0 均受 CVE-2026-60004（CVSS 9.8 RCE）影響；（2）稽核 Gitea 存取記錄，搜尋自 2026/7/29 以來異常的管理員操作、儲存庫複製、大量下載或新建 SSH 金鑰及 webhook；（3）Red Heron 鎖定國防、能源、航太、電信、半導體及政府相關組織——此類組織應進行完整入侵指標比對；（4）確認 Gitea 伺服器的 Linux 環境無非預期核心模組載入（執行 lsmod 並比對正常基線，稽核 /proc/modules），排除 SIXZUT rootkit；（5）若 Gitea 伺服器同處 Proxmox 虛擬化叢集，確認 Proxmox 管理介面無非預期存取記錄及非預期 VM 快照建立。
  • 🔴 確認 Citrix NetScaler 已修補 CVE-2026-88779，稽核 SAML 組態曝險狀態：（1）確認所有 NetScaler ADC 及 Gateway 設備版本，升級至 14.1-73.41 或 13.1-64.28；（2）確認是否配置 SAML SP（show authentication samlAction）或 SAML IdP（show authentication samlIdPProfile）——僅有上述組態的設備才有直接暴露風險；（3）無法立即修補者評估是否可臨時停用 SAML 組態，並以替代方式提供遠端存取；（4）稽核設備記錄，搜尋本週（10/1–10/4）起的 SAML 端點異常請求及非預期系統重啟事件；（5）2026 年已有六個 NetScaler 漏洞進入 CISA KEV——評估是否需要規劃基礎設施升級或替代方案，而非僅被動應對逐一修補。
  • 🔴 立即套用 Atlassian CVE-2026-21589 修補，稽核 Crowd 憑證及管理員帳號：（1）確認所有自架 Atlassian 產品（Jira、Confluence、Bitbucket、Bamboo、Crowd、Jira Service Management、Crucible、Fisheye）已升級至 10/5 發布的修補版本；（2）Crowd 部署須重點稽核：搜尋 WEB-INF/classes/crowd.properties 的存取記錄，確認是否有憑證洩漏；（3）比對管理員帳號建立及群組成員記錄，搜尋 10/1–10/7 期間（漏洞公開窗口）新增的非預期帳號或 jira-administrators 群組成員；（4）Atlassian Cloud 版本已預先修補，僅自架 Data Center 及 Server 版本受影響；（5）自架 Jira DC 可套用 Atlassian 提供的 rewrite.config 臨時緩解檔案作為修補前的過渡措施。
  • 🟡 稽核內部部署 SharePoint 環境並評估 Warlock 殘存風險，強化 API 速率限制防禦自動化爬取：（1）確認所有內部部署 SharePoint Server 已套用 ToolShell 相關漏洞修補（CVE-2025-49704、CVE-2025-49706 等），並輪換 SharePoint 農場帳號密碼、服務帳號憑證及 Web 應用程式金鑰；（2）搜尋 SharePoint 伺服器上的 Webshell（比對 Symantec IoC 中的已知惡意文件雜湊值及路徑），稽核 SYSVOL 共享目錄是否有非預期執行檔；（3）稽核域內是否有 EDR 服務被停用的主機（Warlock 批量部署勒索軟體的前置步驟）；（4）面向神腦國際等台灣電商與零售業者的自動化爬取事件：評估訂單查詢 API 的速率限制、異常行為偵測（單 IP 高頻請求、非正常使用者代理）及 CAPTCHA 機制是否完備，降低自動化爬取風險。
