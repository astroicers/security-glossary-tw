行動建議

  • 🔴 立即修補 Windows IKE Extension CVE-2026-33824（CVSS 9.8，可蠕蟲化，CISA KEV 8/18，FCEB 截止 8/21）：（1）確認所有 Windows 系統（含 Windows 10 1607-22H2、Windows 11 23H2-26H1、Windows Server 2016/2019/2022/2025）已套用 2026 年 4 月 Patch Tuesday 或更新的累積更新；（2）修補前緊急緩解：透過邊界防火牆封鎖 UDP 埠 500（IKE）及 4500（NAT-T IKE）的入站連線（注意此操作會中斷 IKEv2 VPN 連線，應先評估業務影響）；（3）稽核系統日誌中針對 UDP 500/4500 的異常入站連線模式，確認是否已有利用嘗試；（4）對面向網際網路的 Windows 系統（尤其是 VPN 閘道、跳板機及 Windows Server）優先修補。
  • 🔴 立即更新 macOS 以修補 CVE-2026-65400（CVSS 9.8，加密貨幣挖礦，CISA KEV 8/18）：（1）將所有 macOS 裝置升級至 Tahoe 26.6.1、Sequoia 15.7.9 或 Sonoma 14.8.9；（2）若無法立即更新，在「系統設定 → 通用 → 共享」停用 Screen Sharing（螢幕共享），或透過防火牆封鎖 TCP 埠 5900 入站連線；（3）掃描組織內的 macOS 端點，搜尋非預期的加密貨幣挖礦程序（尤其是偽裝為系統程序的 .config/sysmond 或 com.apple.airportd 異常執行檔）及非預期的 SSH 公鑰；（4）確認 LaunchDaemon 及 LaunchAgent 清單中無非預期的持久化項目。
  • 🔴 立即升級 GitLab CE/EE 以修補 CVE-2026-19478（CVSS 9.4，揭露 48 小時後遭積極利用）：（1）確認所有自管 GitLab 實例版本，升級至 18.11.11、19.0.8、19.1.6 或 19.2.4（視目前版本系列選擇對應版本）；（2）無法立即升級時，暫時透過 Web 伺服器設定阻擋對 /api/graphql 端點的外部存取作為緩解，但需評估對 GitLab 功能的影響；（3）審查 GitLab 管理日誌，搜尋 8 月 17 日（漏洞揭露日）後對公開專案的非預期修改或刪除操作；（4）GitLab.com 雲端版已自動更新，無需額外操作。
  • 🔴 監控並準備因應 Microsoft Defender ShieldBreak CVE-2026-69414（CVSS 7.8，零日，尚無修補）：（1）訂閱 Microsoft 安全更新通知（MSRC），在帶外修補程式發布時立即套用；（2）監控 MsMpEng.exe（Defender 核心程序）的子程序執行，非預期的子程序建立可能是利用嘗試的跡象；（3）評估停用 Windows 雲端檔案同步（OneDrive On-Demand Sync）功能的可行性，以縮減 CFAPI 攻擊面；（4）部署額外的特權存取監控（PAM）或 EDR 規則，偵測本機低權限帳號異常的 SYSTEM 等級操作；（5）CISA BOD 26-04 要求 FCEB 機構在 8 月 28 日前套用任何可用緩解措施。
  • 🔴 稽核 Azure 及 Microsoft 365 租戶安全設定（應對 Azure 憑證竊取波及 Fortune 500 事件）：（1）確認所有管理員及特權帳號已啟用多因素驗證（MFA），不允許任何例外；（2）稽核 Azure Entra ID 的應用程式及服務主體（Service Principal）清單，移除具有過度讀取目錄資料（Directory.Read.All）等高權限但不必要的第三方整合；（3）檢視 Azure 登入記錄中的異常存取模式（非常用裝置、非常用位置、大量目錄查詢）；（4）在 Microsoft 365 Defender 中啟用身份識別保護（Identity Protection）及條件式存取（Conditional Access）政策，要求高風險登入時需要重新驗證；（5）評估是否有因第三方 SaaS 整合暴露的 Azure 目錄讀取權限。
  • 🟡 確認 VMware vCenter CVE-2026-59310 修補狀態並執行入侵後鑑識（中國 APT 煙霧彈勒索軟體行動）：（1）確認 vCenter 已修補至 9.1.0.0300、9.0.2.0100 或 8.0 U3k/U2f（上週行動項目延伸確認）；（2）因攻擊者刻意加密 ESXi 日誌（.babyk 副檔名），若發現日誌遭加密，應假設已發生情報蒐集行動而非單純勒索事件；（3）請合格的鑑識調查員檢查 ESXi 主機快照、記憶體映像及網路流量記錄，尋找數據外洩跡象；（4）確認此週發布的 QUIRSO 詳細報告中揭露的新 IOC 已納入安全監控。
  • 🟡 評估並強化量子計算威脅下的密碼學轉型準備（Google Cloud PQC 路線圖參考）：（1）盤點組織內使用非對稱加密（RSA、ECC）保護的長效敏感資料（如法規要求保存 10 年以上的資料），這些資料面臨「先竊取後解密」（Harvest Now, Decrypt Later）的量子威脅；（2）參考 Google Cloud 以 2027 年底為「先竊取後解密」防護完成目標的路線圖，訂定組織的 PQC 遷移優先順序；（3）確認組織使用的雲端服務商及 VPN 廠商的 PQC 支援路線圖；（4）金融業及政府機關應參考 NIST 已標準化的 ML-KEM、ML-DSA 及 SLH-DSA 演算法，開始評估後量子密碼學的導入可行性。
