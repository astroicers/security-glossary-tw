行動建議

  • 🔴 立即修補 Oracle HTTP Server / WebLogic Server Proxy CVE-2026-21962（CVSS 10.0，中國 UNC5174 積極利用）：（1）確認所有 Oracle HTTP Server 及 WebLogic Server（含 Proxy Plug-in for Apache HTTP Server 及 Microsoft IIS）版本，套用 2026 年 1 月 Oracle CPU 修補（若尚未更新）；（2）檢查 Oracle HTTP Server 過去 90 天的存取記錄，搜尋源自非預期地理位置或 IP 的非授權存取嘗試，以及大量 404 或異常 HTTP 回應；（3）若確認使用 Oracle HTTP Server 且對網際網路暴露，立即評估是否能透過防火牆限制存取來源至受信任 IP 範圍作為臨時緩解；（4）確認 Oracle WebLogic 後端應用伺服器是否有非預期的新建連線或進程，評估 SNOWLIGHT 下載器感染的可能性（IoC：異常的網路外傳流量、新建 cron job 或排程任務）。
  • 🔴 立即修補 PaperCut NG/MF 雙零日漏洞（CVE-2026-82078 + CVE-2026-81578）並稽核後 IoC：（1）確認所有 PaperCut NG 及 PaperCut MF 部署版本（24、25、26），立即套用 8 月 28 日發布的第二版緊急修補（須確認為最新版，首版修補已被繞過）；（2）無法立即修補者，立即透過防火牆或 ACL 限制 PaperCut 應用伺服器管理埠（9191 及 9192 等）僅允許受信任 IP 存取，並停止對網際網路直接暴露；（3）修補後應稽核系統設定是否有非預期改動（如新建管理員帳號、修改設定）；（4）搜尋 Web Shell 特徵：PaperCut 應用伺服器目錄中的非預期 JSP 或 Groovy 腳本檔案，以及 server-command.log 中的異常命令執行記錄；（5）確認是否有非預期的外部連線（反向 Shell 或遠端存取工具的出站連線）。
  • 🔴 立即修補 Citrix NetScaler ADC/Gateway CVE-2026-8452（pre-auth RCE，CISA KEV 8/26，FCEB 截止 8/29）：（1）確認所有 NetScaler ADC 及 NetScaler Gateway 版本，立即升級至 14.1-73.32、13.1-63.21 或更新版本（參照 Citrix 公告 CTX696604）；（2）修補後掃描設備上的非預期 Web Shell（特別是 NetScaler 的 /netscaler/ 及 /nsconfig/ 目錄）；（3）稽核設備管理員登入記錄及 AAA 事件記錄，確認是否有未授權的認證嘗試或設定變更；（4）若有設備尚未修補，應立即透過網路 ACL 限制 Gateway VPN 及 AAA 虛擬伺服器的存取來源，並優先修補面向網際網路的設備。
  • 🔴 確認 APT24 廣告供應鏈攻擊影響並加強台灣廣告聯播安全：（1）若組織網站採用第三方廣告聯播服務，應立即聯繫廣告聯播商確認其系統是否受 APT24 相關入侵影響；（2）稽核網站前端程式碼（含廣告腳本），搜尋呼叫非預期外部域名（如 analytics.czbook[.]org）的 JavaScript 片段；（3）部署內容安全政策（CSP）限制網站允許載入的第三方腳本來源，降低廣告腳本投毒的攻擊面；（4）員工若使用台灣新聞網站或小說平台（包含太報、小說狂人等），應確認端點防護是否已偵測到 BadAudio 相關 IoC，並確認近期無異常網路連線至 analytics.czbook[.]org。
  • 🟡 套用 OpenSSL 8/28 安全更新並評估 QUIC 服務暴露面：（1）確認所有部署 OpenSSL 4.0、3.6、3.5、3.4 或 3.0 版本的系統（特別是使用 QUIC 功能的伺服器），套用 8 月 28 日發布的安全更新；（2）識別組織內對外暴露 QUIC 服務的端點（如使用 HTTP/3 的 Web 伺服器），評估其對 CVE-2026-18798 的暴露風險；（3）若使用 OpenSSL CMS 功能處理外部傳入的 S/MIME 或 CMS 訊息，應確認 CVE-2026-63072 的修補已套用，避免惡意 CMS 訊息導致的 DoS 攻擊。
  • 🟡 加強台灣製造業廠商入侵偵測並縮短事件揭露時程：（1）貿聯-KY 及群光電子事件提醒台灣高科技製造業應持續強化網路側向移動偵測能力（使用者行為分析、異常登入偵測）；（2）台灣上市企業資安長應確認重大資安事件揭露流程符合主管機關要求，縮短從偵測到公告的時間差（貿聯案延遲三天），避免監理及市場信任風險；（3）供應鏈連動評估：確認自家廠商及客戶中是否有同類製造業者近期遭受攻擊，評估橫向連動風險。
