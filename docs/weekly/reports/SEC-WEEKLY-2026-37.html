行動建議

  • 🔴 立即套用 Microsoft 9 月 Patch Tuesday 更新，重點處理兩個 Windows 零時差（CVE-2026-81963 Windows Update Stack EoP、CVE-2026-85880 Windows ALPC EoP），CISA 截止日為 9 月 22 日。建議措施：（1）透過 SCCM、Intune 或 WSUS 確認所有 Windows 端點已完整安裝 9 月份累積更新，特別核查 Windows Update Stack 相關補丁的安裝狀態；（2）透過 EDR 設定告警，監控 Windows Update 相關程序（TrustedInstaller.exe、MoUsoCoreWorker.exe）生成非預期子程序的行為；（3）若環境中存在無法立即更新的系統（如舊版 Windows Server），應優先隔離此類系統的本地存取並啟用額外稽核記錄；（4）同步評估 Oracle 9 月安全更新——超過 100 個 Critical 等級漏洞中有 240 個以上可無驗證遠端利用，Oracle Database、Middleware 及 Java SE 應納入本月修補計畫。
  • 🔴 緊急處置 Cisco Secure Firewall Management Center CVE-2026-20079（CVSS 10.0）：（1）確認 FMC 版本是否早於 7 月 29 日修補版本，立即套用可用更新；（2）稽核 FMC 主機過去 60 天的 HTTP 存取記錄，搜尋非預期 IP 對 FMC 管理介面的存取及 root 執行任意指令的跡象；（3）搜尋入侵後指標：/var/tmp 或 /opt/cisco 下的非預期 Web Shell 或 JAR 檔案、異常 Netcat 或 Socat 連線程序、非預期的出站 TCP 連線（特別是通往非授權 IP 的高連接埠流量）；（4）若偵測到任何入侵指標，應立即隔離 FMC 主機並啟動事件響應程序——FMC 被控制後攻擊者可修改所有防火牆策略、開放惡意通訊埠；（5）聯邦機構截止日為 9 月 12 日已過，台灣政府機關及金融業應將此視為最高優先修補項目。
  • 🔴 立即修補 Citrix NetScaler CVE-2026-19490 及 MikroTik RouterOS（CVE-2026-86060 / CVE-2026-67276）： NetScaler：（1）套用 8 月 19 日修補版本；（2）稽核 NetScaler Gateway 及 ADC 自 9 月 3 日起的存取記錄，搜尋未驗證連線成功進入管理介面或 VPN 隧道的記錄；（3）若 NetScaler 暴露於網際網路且尚未修補，應立即在防火牆層限制管理介面存取來源 IP。 MikroTik：（1）立即升級至 RouterOS 6.49.21（長期版）、7.23.4（長期版）或 7.24.2（穩定版）；（2）若無法立即升級，應封鎖外部 SSH 存取（TCP 22）或限制 SSH 僅允許管理 IP 存取；（3）確認路由器管理記錄是否有 9 月 3 日前的異常登入，特別注意以特殊字元開頭的使用者名稱。台灣 ISP、教育機構及中小企業應優先盤點環境中 MikroTik 設備數量及版本。
  • 🔴 從中科院委外廠商入侵事件強化供應鏈安全管控：（1）盤點所有委外開發或維護的系統，要求廠商提供完整原始碼稽核報告，特別關注是否存在未文件化的管理介面、隱蔽排程函數或硬編碼憑證；（2）針對所有委外系統的對外介面執行網路掃描，識別非預期暴露的管理端點；（3）要求委外廠商提供系統存取記錄，稽核過去 90 天內廠商 IP 的存取行為是否逾越合約範圍；（4）在與委外系統相連的網路節點部署額外監控，對非正常工作時間或境外 IP 的存取設定即時告警；（5）政府機關及國防相關供應鏈廠商應依《資通安全責任等級分級辦法》檢視委外合約中的資安責任歸屬條款，確保廠商後門行為有明確法律究責依據。
  • 🟡 修補 WSO2 API Manager CVE-2026-5430 及 Fortinet CVE-2025-25249，並主動搜尋入侵指標： WSO2（CVE-2026-5430 CVSS 9.8）：（1）立即升級受影響版本至修補版本；（2）稽核 API Manager 過去 30 天的存取記錄，搜尋使用不支援演算法（如 HS256 搭配 RS256 公鑰）的 JWT 令牌；（3）若發現異常令牌，應視為帳號已遭接管，輪換所有 API 金鑰及服務帳號憑證。 Fortinet（CVE-2025-25249）：（1）套用廠商修補；（2）搜尋 PivotC2 入侵指標：FortiOS 設備上的異常 Node.js 程序、連往非授權目的地的 HTTPS 混合 WebSocket 連線；（3）比對 SOCRadar 發布的 PivotC2 IOC 清單進行全環境掃描。
  • 🟡 針對 BambooToken 及 MQTT C2 威脅強化偵測能力：（1）在防火牆及 NIDS 新增 MQTT 相關規則，監控 TCP 1883（未加密 MQTT）及 TCP 8883（加密 MQTTS）的出站連線，特別是連往非授權 MQTT 代理伺服器的流量；（2）若環境中使用 Tendyron OnKey 軟體或有中國銀行業 IT 往來，應立即掃描相關工作站是否存在 BambooToken IOC（DLL 側載行為、SoftEther VPN 程序）；（3）在 EDR 平台設定告警規則，監控合法軟體程序載入非預期 DLL 的行為（DLL 側載偵測）；（4）向紅隊或威脅獵捕團隊提交 Lumen Black Lotus Labs 發布的 BambooToken IOC 清單，執行歷史記錄回溯搜尋，確認是否有潛伏三年以上但尚未被發現的感染。
  • 🟢 從商周集團攻擊事件評估台灣媒體業及電商平台的資安基線：（1）媒體集團及電商業者應評估 DDoS 防護、CDN 快取策略及應用層 WAF 設定，確保關鍵服務具備基本韌性；（2）擁有百萬以上訂閱用戶資料庫的組織應確認《個人資料保護法》下的資料外洩通報義務，並測試通報程序是否可在 72 小時內完成（符合歐盟 GDPR 標準，中華民國個資法雖無明定時限，但主管機關已日益要求速報）；（3）若攻擊確認涉及資料外洩，商周集團應於確認後儘速向個資保護機關通報並對受影響用戶發出通知，以降低次生損害。
